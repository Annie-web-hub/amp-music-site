# AMP! Independent Music Culture

A colorful music discovery landing page built with React, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Publish with GitHub Pages

This repository is prepared to deploy from the `main` branch with GitHub Actions. Create a public GitHub repository named `amp-music-site`, push this project to it, then open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.

After the first successful deployment, the site will be available at:

`https://<your-github-username>.github.io/amp-music-site/`

The photos and sample audio are loaded from external URLs.
